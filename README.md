# iroha — Prompt Studio

日本語の選択肢から、SeaArt AIなどへ貼り付ける英語プロンプトを組み立てるWebプロトタイプです。PC・スマートフォン向けのレスポンシブUIに対応しています。

## 起動

Node.js 22以降とnpmを使用します。

```sh
npm ci
npm run dev
```

本番用ビルドとローカル確認：

```sh
npm run build
npm run preview
```

ビルドすると、通常の配信用ファイルに加え、CSS・JavaScriptを内包した単体版 `dist/iroha-prototype.html` も生成します。外部APIや外部画像には依存しません。データの保存先を固定するため、継続利用では同じURLからのアクセスを推奨します。

生成・差分・競合処理・バックアップ検証のテスト：

```sh
npm test
```

実ブラウザでの操作テスト：

```sh
npx playwright install chromium
npm run test:ui
```

Linuxで `/usr/bin/chromium` がある場合はそちらを使用します。その他の実行ファイルを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` で指定できます。

## 基本操作

1. 必要ならキャラクターを選び、髪型・衣装の差分を指定します。
2. カテゴリや検索から日本語タグを選びます。未選択の指定は出力しません。
3. ポジティブ／ネガティブの出力を確認してコピーします。
4. 再利用する組み合わせは保存します。成功した英文は「原文で登録」から、記号や改行を保持して保存できます。

キャラクターとタグ辞書は画面内で追加・編集できます。英語の手動編集版は選択状態と独立して保持され、以後の選択変更で上書きされません。通常の生成へ戻す操作では確認が入ります。

## データの保存・移行

データは現在のブラウザのIndexedDBに保存します。ログインや外部APIへのデータ送信はありません。ブラウザ、端末、アクセスするドメインが違えば保存先も別です。

「保存とバックアップ」からJSONを書き出して保管してください。別端末でも同じJSONを読み込めます。復元は全体置換で、マージはしません。形式を検証し、置換前のデータを端末内に退避します。前回の退避データも設定から書き出せます。

サイトデータの削除やプライベートブラウズによって登録内容が失われる可能性があります。大切な登録内容は定期的に書き出してください。

## PDF・Wordからの辞書一括登録

作成画面または辞書画面の「資料から一括登録」を開きます。

1. PDF・Word（`.docx`）・TXT・CSV・TSVを選択するか、一覧を直接貼り付けます。
2. 「対訳表」「1行1フレーズ」「プロンプトのカンマ分割」から読み取り方を選びます。
3. 登録先カテゴリ・通常／成人向けの区分を指定し、「登録候補を確認」を押します。
4. 候補の日本語名・英語・カテゴリを確認し、必要なものだけ一括登録します。

日本語と英語のペアはタブ・`→`・`|`・引用符付きCSVで区切れます。例：

```text
白いシャツ → white shirt
柔らかい光 → soft lighting
```

英語だけの一覧は、英語を表示名にして登録できます。自動翻訳や新しい表現の生成は行いません。対訳がない日本語の文章から、英語を推測する機能もありません。

既存と同じ英語は上書きせずにスキップします。括弧・重み付け・エスケープを保持し、カンマ分割は明示的に選んだときだけ行います。登録しても作成中のプロンプトへ自動追加しません。

資料の読み取りは端末内で実行し、ファイルをサーバーやAIへ送信しません。元の資料全体は保存せず、確認して登録したフレーズだけを辞書へ保存します。

上限は1ファイル10MB・PDF200ページ・抽出100万文字・1回2,000候補です。Wordの対訳表はセル間をタブとして抽出しますが、結合セル・段組み・複雑なPDFは確認が必要です。画像だけのPDFにはOCRが必要で、現版にはOCRを含めていません。旧形式`.doc`はWordで`.docx`へ保存し直してください。

## プロトタイプの範囲

### 拡張辞書 v2

タグは471件（通常451件・成人向け衣装20件）です。服装・ポーズ・表情・構図・背景・照明・画風・外見・ネガティブの9カテゴリを収録しています。日本語と英語のほか、登録された別名でも検索できます。ひらがな・カタカナ・全角英数字を揃えて検索し、空白で区切るとAND検索になります。

「すべて／選択済み」「種類」で絞り込めます。「成人向け衣装」をONにすると、非露骨なランジェリー・水着・ナイトウェア等の辞書と「成人向けのみ」が表示されます。ONにしただけではタグを追加しません。OFFでは成人向けに分類された選択を外します。原文・手動編集・自由入力は解析も削除もしません。この切替は辞書の表示と構造化した選択に作用します。

初回の更新時は、追加辞書だけを既存データへ補います。編集済みタグ・キャラクター・保存済み原文は上書きせず、削除した標準タグも復活させません。旧版のJSONバックアップにも対応しています。別の端末・ブラウザ・保存先へ移すときは、旧版からJSONを書き出し、更新版で復元してください。

辞書編集では、検索用キーワード（30個以内）と成人向け分類を設定できます。

- 構造化した選択操作は1キャラクターが対象です。
- 複数人物・重み付けの専用操作、クラウド同期、モデル別自動変換には未対応です。既存の英文構文は原文として保存できます。
- 自由入力内のタグ分解・矛盾検出・重複除去は行いません。
- サンプルのキャラクターと英語辞書は編集用のたたき台です。使用モデルに応じて調整してください。
- 画像の生成やSeaArt AIへの直接送信は行いません。
- 同じデータを複数タブで同時編集する運用は避けてください。
